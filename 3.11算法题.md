## [102. 二叉树的层序遍历 ](https://leetcode.cn/problems/binary-tree-level-order-traversal/description/)

![image-20260311213127153](https://aaswk.oss-cn-beijing.aliyuncs.com/image-20260311213127153.png)

层序遍历用到广度优先搜索，通过队列解决

```c++
class Solution {
public:
    vector<vector<int>> levelOrder(TreeNode* root) {
        vector<vector<int>> res;
        queue<TreeNode*>q;
        //先将根节点加入队列
        if(root) q.push(root);
        while(!q.empty()){
            //记录队列元素数量，决定应该出队的数量（每层元素的个数）
            int size=q.size();
            
            vector<int> v;
            for(int i=0;i<size;i++){//每层
                TreeNode*node=q.front();
                q.pop();
                v.push_back(node->val);
                if(node->left) q.push(node->left);//将左右子节点加入队列
                if(node->right) q.push(node->right);
            }
            res.push_back(v);
        }
        return res;
    }
};
```

## [101. 对称二叉树 - 力扣](https://leetcode.cn/problems/symmetric-tree/)

![image-20260311220333317](https://aaswk.oss-cn-beijing.aliyuncs.com/image-20260311220333317.png)

二叉树类的题目最重要的是确定如何遍历，这道题只能用后序遍历（左右中），因为需要先比较左右节点是否对称，再返回给父节点

```c++
class Solution {
public:
    bool compare(TreeNode* left,TreeNode*right) {
        //先排除空节点的情况
        if(left==NULL&&right!=NULL) return false;
        else if(left!=NULL&&right==NULL) return false;
        else if(left==NULL&&right==NULL) return true;
        else if(left->val!=right->val) return false;//排除数值不相等的情况
		
        //左右节点都不为空且数值相同，做递归判断
        bool outside=compare(left->left,right->right);//左子树的左和右子树的右，外层比较
        bool inside=compare(left->right,right->left);//左子树的右和右子树的左，内层比较
        bool isSame=outside && inside;//左子树的中和右子树的中
        return isSame;
    }

    bool isSymmetric(TreeNode*root){
        if(root==NULL) return true;
        return compare(root->left,root->right);
    }
};
```
