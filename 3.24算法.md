## [105. 从前序与中序遍历序列构造二叉树](https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-inorder-traversal/description/)

![image-20260324125957944](https://aaswk.oss-cn-beijing.aliyuncs.com/image-20260324125957944.png)



![image-20260324131048477](https://aaswk.oss-cn-beijing.aliyuncs.com/image-20260324131048477.png)

- 第一步：如果数组大小为零的话，说明是空节点了。
- 第二步：如果不为空，那么取前序数组第一个元素作为节点元素。
- 第三步：找到前序数组第一个元素在中序数组的位置，作为切割点
- 第四步：切割中序数组，切成中序左数组和中序右数组 （顺序别搞反了，一定是先切中序数组）
- 第五步：切割前序数组，切成前序左数组和前序右数组
- 第六步：递归处理左区间和右区间

```c++
class Solution {
public:
    TreeNode* buildTree(vector<int>& preorder, vector<int>& inorder) {
        //第一步
        if(preorder.empty()||inorder.empty()) return nullptr;
        
        //第二步
        int rootVal=preorder[0];
        TreeNode*root=new TreeNode(rootVal);
        
        //第三步
        int i;
        for(i=0;i<inorder.size();i++){
            if(rootVal==inorder[i]) break;
        }
        
        //第四步
        vector<int> leftinorder(inorder.begin(),inorder.begin()+i);
        vector<int> rightinorder(inorder.begin()+i+1,inorder.end());
        
        preorder.erase(preorder.begin());
        
        //第五步
        vector<int> leftpreorder(preorder.begin(),preorder.begin()+leftinorder.size());
        vector<int> rightpreorder(preorder.begin()+leftinorder.size(),preorder.end());
		
        //第六步
        root->left=buildTree(leftpreorder,leftinorder);
        root->right=buildTree(rightpreorder,rightinorder);
        return root;
    }
};
```

## [530. 二叉搜索树的最小绝对差](https://leetcode.cn/problems/minimum-absolute-difference-in-bst/description/)

![image-20260324160028096](https://aaswk.oss-cn-beijing.aliyuncs.com/image-20260324160028096.png)

时刻记住二叉搜索树的中序遍历是递增序列

```c++
class Solution {
public:
    //中序遍历函数
    void traversal(TreeNode*root,vector<int> &res){
        if(root->left) traversal(root->left,res);//左
        res.push_back(root->val);//中
        if(root->right) traversal(root->right,res);//右
    }
    
    int getMinimumDifference(TreeNode* root) {
        vector<int> res;
        traversal(root,res);
        
        //比较相邻两个数的差值
        int minx=INT_MAX;
        for(int i=1;i<res.size();i++){
                if(abs(res[i]-res[i-1])<minx) minx=abs(res[i]-res[i-1]);
        }
        return minx;
    }
};
```
