## [236. 二叉树的最近公共祖先](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/description/)

![image-20260326182228730](https://aaswk.oss-cn-beijing.aliyuncs.com/image-20260326182228730.png)

递归函数的含义：返回以root为根的树中，p和q的最近公共祖先

```c++
class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        //结束条件
        if(root==nullptr||root==p||root==q) return root;
        //递归左右子树
        TreeNode*left=lowestCommonAncestor(root->left,p,q);
        TreeNode*right=lowestCommonAncestor(root->right,p,q);
        //返回规则
        if(left!=nullptr&&right!=nullptr) return root;
        if(left!=nullptr) return left;
        if(right!=nullptr) return right;
        return nullptr;
    }
};
```

## [701. 二叉搜索树中的插入操作](https://leetcode.cn/problems/insert-into-a-binary-search-tree/)

![image-20260326190518301](https://aaswk.oss-cn-beijing.aliyuncs.com/image-20260326190518301.png)

将val值插入到以root为根节点的子树中，并返回插入后该子树的根节点

原理：先处理子树（递归调用），用返回值更新当前节点的孩子，最后返回当前节点自身。**用于需要保留当前节点，并修改其子树结构的场景**

```c++
class Solution {
public:
    TreeNode* insertIntoBST(TreeNode* root, int val) {
        if(root==nullptr){
            TreeNode*node=new TreeNode(val);
            return node;
        }
        //用root->left接收，（插入后/操作后）root左子树的根节点
        if(root->val>val) root->left=insertIntoBST(root->left,val);
        if(root->val<val) root->right=insertIntoBST(root->right,val);  
        //返回root为当前节点（当前根节点）
        return root;
    }
};
```
