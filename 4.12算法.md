## [63. 不同路径 II](https://leetcode.cn/problems/unique-paths-ii/description/)

![image-20260406145525053](https://aaswk.oss-cn-beijing.aliyuncs.com/image-20260406145525053.png)

第一行和第一列都只有一条路径可以到达，如果有障碍物，那这一行后边和这一列下边都走不到，所以初始值依旧为0

到达`dp[i][j]`依旧是由`dp[i-1][j]`和`dp[i][j-1]`的加和，如果遇到障碍物就跳进下一层循环

```c++
class Solution {
public:
    int uniquePathsWithObstacles(vector<vector<int>>& obstacleGrid) {
        int m=obstacleGrid.size();//行
        int n=obstacleGrid[0].size();//列
        vector<vector<int>> dp(m,vector<int>(n,0));
        //初始化
        for(int i=0;i<m;i++){
            if(obstacleGrid[i][0]==1) break;//遇到障碍物
            dp[i][0]=1;
        }
        for(int j=0;j<n;j++){
            if(obstacleGrid[0][j]==1) break;//遇到障碍物
            dp[0][j]=1;
        }
        //递推
        for(int i=1;i<m;i++){
            for(int j=1;j<n;j++){
                if(obstacleGrid[i][j]==1) continue;
                dp[i][j]=dp[i-1][j]+dp[i][j-1];
            }
        }
        return dp[m-1][n-1];
    }
};
```

## [239. 滑动窗口最大值](https://leetcode.cn/problems/sliding-window-maximum/description/)

![image-20260412203439194](https://aaswk.oss-cn-beijing.aliyuncs.com/image-20260412203439194.png)

```c++
class Solution {
public:
    vector<int> maxSlidingWindow(vector<int>& nums, int k) {
        deque<int> dq;
        vector<int> v(nums.size()-k+1);
        for(int i=0;i<nums.size();i++){
            //移除比要添加的元素小的值，维护队列单调性
            while(!dq.empty()&&nums[i]>=nums[dq.back()]){
                dq.pop_back();
            }
            dq.push_back(i);//移除后添加该元素

            //移除过期元素
            if(!dq.empty()&&i-k+1>dq.front()){
                dq.pop_front();
            }
            //记录答案（队首元素的值）
            if(i-k+1>=0){
                v[i-k+1]=nums[dq.front()];
            }
        }
        return v;
    }
};
```
